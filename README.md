# ToolForge CNC — téléchargements

Ce dépôt ne contient que les **installateurs Windows** de ToolForge CNC.
Le code source est privé.

## Installer

1. Ouvrir **[la dernière version](https://github.com/stompra/toolforge-cnc-releases/releases/latest)**.
2. Télécharger `ToolForge-CNC-Setup-….exe` et l'ouvrir.
3. Si Windows affiche « Windows a protégé votre ordinateur » : **Informations complémentaires** → **Exécuter quand même**
   (le logiciel n'est pas encore signé numériquement).

L'installation ne demande pas de droits administrateur.

## Mettre à jour

Rien à télécharger à la main : au démarrage, ToolForge affiche **« Mise à jour disponible »** en bas à droite de l'accueil.
Un clic pour télécharger, un clic pour redémarrer.

Les plans ouverts dans ToolForge restent sur le poste : seules les mises à jour passent par internet.
